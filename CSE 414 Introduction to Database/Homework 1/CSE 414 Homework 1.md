# Building a NoSQL Database System for Banking Operations 
    The objective of this assignment is to design, implement, and query a NoSQL database system tailored for managing banking operations.
# Tasks
## Designing the Schema
    Design a schema for the NoSQL database that efficiently stores information relevant to banking operations (customers, accounts, transactions, and branches).Consider the relationships between different entities and how they can be represented in the database.Ensure the schema is scalable and flexible to accommodate future requirements and changes in banking operations.
## Implementing the Database:
    Choose a suitable NoSQL database technology (e.g., MongoDB, Cassandra, DynamoDB) for implementing the designed schema. Set up the NoSQL database environment. Create the necessary collections, tables, or documents as per the designed schema.
