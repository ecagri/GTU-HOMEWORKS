# CSE 414 Homework 2

**Deadline (09.06.2024)**

Suppose that you are developing a management system database related to the health sector (a hospital, a health care center, etc). Give the schema of the database.

1) Create 3 different SQL functions needed for the management system.
    + One must be a table SQL function. (10 pts)
    + One must include a for loop. (15 pts)
    + One must have a variable as input, a temporary variable and return a variable as an output. (10 pts)

2) Create 4 triggers needed for the management system.
    + One must use “referencing old row as” and “referencing new row as” together. (10 pts)
    + One must have “when” or “if”. (15 pts)
    + One must have “for each row”. (20 pts)
    + Write the statement in SQL to drop a trigger.
    + Write the statement in SQL to show triggers. (10 pts)

3) Create 2 atomic transactions needed for the management system. They must be different from the previous questions. (10 pts)

*Note: You will not be graded from giving the schema but answers without the schema will not be graded.*
